# Vinduskalkulator En responsiv tilbudskalkulator for vinduer på norsk, klar for GitHub Pages. ## Funksjoner - To brukernivåer: **Kunde** og **Fagperson** - Norsk språk - Flere vindustyper og materialer - 2-/3-/4-lags glass og spesialglass - Farger, sprosser, beslag og tilvalg - Montering, demontering, finish og frakt - Margin, rabatt og MVA - Flere vinduer i samme tilbud - Lokal lagring i nettleseren - Utskrift / PDF - Kopiering av tilbudstekst - Forenklet teknisk kontroll tilpasset norske forhold ## Bruk av de to modusene - **Kunde**: for boligeier eller kunde som vil fylle ut en enkel forespørsel og få et veiledende tilbud. - **Fagperson**: for selger, montør eller leverandør som vil styre tekniske valg, prisgrunnlag, margin og kontrollpunkter. ## Publiser på GitHub Pages 1. Opprett et nytt GitHub-repository, for eksempel `vinduskalkulator`. 2. Last opp `index.html` og `README.md` til repositoryets rotmappe. 3. Gå til **Settings → Pages**. 4. Under **Build and deployment**, velg **Deploy from a branch**. 5. Velg branch **main** og mappe **/(root)**. 6. Trykk **Save**. 7. Etter publisering får du en offentlig URL som kan deles med kunder. ## Viktig før kommersiell bruk Prisene i kalkulatoren er eksempelverdier. Oppdater grunnpris pr. m², minimumspriser, tilvalg, frakt, margin og montering i `index.html` til dine faktiske leverandør- og salgstall.
